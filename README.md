#  LAB-WEB-12-2026

Halo, teman-teman! 👋 Selamat datang di repositori resmi **LAB-WEB-12-2026**.

Repositori ini dipakai sebagai wadah pengumpulan tugas praktikum untuk mata kuliah **Praktikum Pemrograman Web** Tahun 2026. Ikuti langkah-langkah di bawah ini agar proses pengumpulan tugas kalian berjalan lancar.

##  Cara Mengumpulkan Tugas

### 1. Fork Repositori Ini
Buka halaman repositori ini, lalu klik tombol **Fork** di pojok kanan atas untuk menyalinnya ke akun GitHub kalian sendiri.

### 2. Ambil URL Hasil Fork
Masuk ke repositori hasil fork di akun kalian, klik tombol **Code**, lalu salin URL-nya.

### 3. Siapkan Terminal
Buka Terminal, Git Bash, atau Command Prompt di folder tempat kalian ingin menyimpan repositori.

### 4. Clone ke Komputer Lokal
Gunakan URL yang sudah disalin untuk meng-clone repositori:

```
git clone <url-repositori-kalian>
```

### 5. Masuk ke Folder Repositori

```
cd LAB-WEB-13-2026
```

### 6. Buat Branch dengan NIM Kalian
Setiap mahasiswa wajib membuat branch sendiri menggunakan NIM masing-masing.

```
git checkout -b H07125xxxxx
```

> Ganti `H07125xxxxx` dengan NIM kalian sendiri.

### 7. Masuk ke Folder Sesuai NIM

```
cd H07125xxxxx
```

### 8. Kerjakan Tugasnya
Tambahkan file tugas sesuai instruksi yang diberikan asisten. Pastikan semua file disimpan di dalam folder NIM masing-masing.

### 9. Tambahkan Perubahan ke Git

```
git add .
```

Cek dulu perubahan yang sudah ditambahkan dengan:

```
git status
```

### 10. Commit Pekerjaan Kalian
Buat commit dengan pesan yang deskriptif sesuai tugas yang dikerjakan.

```
git commit -m "Tugas 1: HTML sebagai Kerangka"
```

### 11. Push ke Repositori Fork

```
git push -u origin H07125xxxxx
```

> Sesuaikan `H07125xxxxx` dengan NIM kalian.

### 12. Ajukan Pull Request
Buka repositori fork kalian di GitHub, lalu buat **Pull Request** dari branch pribadi menuju repositori utama **LAB-WEB-13-2026**.

Sebelum membuat Pull Request, pastikan:

-  File tugas sudah berada di folder NIM yang benar
-  Semua perubahan sudah di-`add`
-  Perubahan sudah di-`commit`
-  Nama branch sesuai NIM kalian
-  Branch sudah berhasil di-`push` ke GitHub

-  Tulis pesan commit yang informatif dan mudah dipahami.
-  Ikuti struktur folder sesuai ketentuan yang berlaku.
